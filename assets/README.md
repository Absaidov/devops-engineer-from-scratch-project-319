# Скриншоты наблюдаемости

Фактическое развёртывание управляемой наблюдаемости подтверждают:

- `yandex-monitoring-kubernetes.png` — Terraform-дашборд системных метрик;
- `yandex-monitoring-application.png` — Prometheus-панели приложения;
- `yandex-cloud-logging.png` — отфильтрованные логи namespace `bulletins`;
- `yandex-monitoring-alert.png` — тестовый алерт в состоянии `FIRING` или полученное уведомление.

Скриншоты прежнего стенда Grafana оставлены как история предыдущего этапа и не заменяют перечисленные подтверждения управляемых сервисов Yandex Cloud.
